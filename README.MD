## Tentang Repository Ini

Secara garis besar, `geguritan` adalah ruang kerja dan arsip untuk pengembangan karya sastra. Fokus utamanya bertumpu pada **Bahasa Jawa** *(entah sejenak singgah, atau menetap selamanya)*.

Cakupan utama repository ini meliputi:
- Penulisan syair, pujian, dan geguritan.
- Penyusunan lirik, bank diksi, dan penelitian kebahasaan.
- Arsip materi primer dan referensi pendukung.

Meskipun menitikberatkan pada **Bait-bait syi'ir sakral dan pujian bernafas tradisi Jawa**, repository ini sesekali juga memuat sisipan fokus lain, seperti; Pernyataan hajat tradisional, arsip eksperimen penulisan, kerangka lirik atau nada, serta dokumentasi draf pemikiran lainnya.
