## Tentang Repository Ini

`geguritan` adalah ruang kerja dan arsip pengembangan karya sastra, syair, lirik, diksi, penelitian bahasa, serta berbagai bahan pendukung yang berkaitan dengan pengembangan karya.

Repository ini dapat memuat:

* karya sastra dan syair;
* purwarupa dan draft;
* bank diksi;
* penelitian dan audit kebahasaan;
* konstitusi atau pedoman penyusunan karya;
* framework pengembangan;
* sumber primer dan referensi;
* materi keagamaan;
* karya pihak ketiga;
* serta dokumentasi pendukung.

Karena sifat materinya beragam, **jangan menganggap keberadaan suatu file di repository ini sebagai pemberian izin otomatis untuk menggunakan file tersebut.**

## ⚠️ Jangan Menganggap Repository Ini Sebagai Satu Paket Lisensi

Keberadaan satu materi yang bebas digunakan **tidak berarti seluruh isi repository bebas digunakan**.

Sebaliknya, keberadaan materi pihak ketiga **tidak mengurangi kebebasan yang telah diberikan terhadap karya yang memang secara eksplisit berada di bawah Lisensi Syair Bebas Mutlak**.

Untuk menentukan apakah suatu karya dapat digunakan, selalu periksa:

1. lokasi file atau direktori;
2. `LICENSE.md` yang berlaku;
3. pemberitahuan hak pada file tersebut;
4. serta sumber asli apabila materi tersebut merupakan karya pihak ketiga.

## 🧭 Struktur Lisensi

Secara umum:

```text
geguritan/
│
├── README.md
├── Repository Licensing Notice.md
│
├── ANDRA SAYEKTI/
│   ├── LICENSE.md
│   └── karya-karya yang dibebaskan
│
├── FINAL/
│   ├── LICENSE.md
│   └── karya final yang dibebaskan
│
├── Primary Source/
│   └── sumber dan referensi
│
└── materi lainnya/
```

Struktur tersebut menunjukkan **cakupan**, bukan berarti setiap direktori di atas memiliki status hukum yang sama.

Untuk perubahan atau penambahan wilayah yang menggunakan Lisensi Syair Bebas Mutlak, `Repository Licensing Notice.md` dan `LICENSE.md` pada wilayah tersebut harus diperbarui secara bersamaan.
