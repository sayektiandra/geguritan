# Prinsip Transkripsi Lantunan

Naskah syair dapat menggunakan penyesuaian penulisan bunyi
untuk menjaga ketepatan pelafalan saat dilantunkan.

Penyesuaian ini tidak selalu mengikuti ejaan baku,
melainkan mengikuti kebutuhan irama, rima, dan pelafalan.

Contoh:

wilasa → wilaso
kawula → kawulo
bawana → bawono

Perubahan penulisan tidak mengubah makna kata.
